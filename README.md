# Apple Reminders · macOS 提醒事项写入工具

把一句口语化的提醒文本（例如「提醒：明天上午 10 点去医院复查，带医保卡」）转换成 macOS「提醒事项」应用里的真实提醒条目。每条自动带上**标题、到期时间、地点、备注和到点通知**，并逐条读回校验确保写入成功。

本项目同时是：

- 一个**可直接手动调用**的命令行工具（Swift 脚本，只依赖苹果系统框架）；
- 一个设计为 **AI Agent Skill** 的契约包（通过 `SKILL.md` 定义「把口语文本拆成 JSON」的规则，`WriteReminders.swift` 作为执行腿落地）。

---

## 特性

- **纯标准输入传递数据**：全程不写临时文件、不产生中间产物，运行结束只留下提醒事项本身。
- **字段齐全**：标题、到期时间、地点、备注、到点通知一次设好。
- **宽松的时间解析**：支持 `yyyy-MM-ddTHH:mm` 含时刻，也支持纯日期 `yyyy-MM-dd`（未给时刻则默认当天 09:00 推送）。
- **写入即校验**：每条写入后按标识读回，核对标题、日期、时刻、地点、通知数量，不一致即失败。
- **多提醒一次写**：一段文本含多个事件时，可一次传入多条 JSON。
- **只依赖系统框架**：无需安装任何第三方依赖，macOS 自带 Swift 即可运行。

## 提醒 vs 日历事件（看个人选择）

本项目只写「提醒事项」，而不在日历里新建事件（event）。

| 维度   | 提醒事项（Reminder）  | 日历事件（Event）        |
| ---- | --------------- | ------------------ |
| 落点   | 独立的「提醒事项」清单     | 日历的时间格子里，像会议或约会占一块 |
| 时间   | 只设到期时间，到点弹通知    | 有明确的起止时间段，进日历排程视图  |
| 打开方式 | 在提醒事项 App 里勾选完成 | 在日历 App 里查看/安排     |
| 适用场景 | 「到点了提醒我去做某事」    | 「某段时间被安排了某项活动」     |

1. **EventKit 直写提醒**（当前 skill）—— macOS 零弹窗，但提醒只是「到点弹通知」，不进日历格子
2. **.ics 文件导入日历**—— **跨平台通用**：Windows（Outlook/Google/QQ mail日历）、安卓、iOS 都能用，但需要一个导入确认步骤，个人觉得麻烦，而且没有“打勾确认”的地方，占着格子感觉像一直**没完成**

## 环境要求

- macOS（写入提醒依赖 Apple EventKit，仅支持 macOS）
- 系统自带 Swift（Xcode Command Line Tools，运行 `swift --version` 确认）

> ⚠️ **仅 macOS 可用**。Windows、iOS/Android 上 EventKit 不存在，本项目不适用（详见「跨平台说明」）。

## 使用

### 方式一：标准输入传 JSON（推荐）

```bash
swift scripts/WriteReminders.swift <<'JSON'
[
  {
    "title": "去朝阳医院复查",
    "due": "2026-11-12T10:00",
    "place": "朝阳医院门诊楼三层",
    "notes": "带医保卡和上次检查结果"
  },
  {
    "title": "项目周会",
    "due": "2026-11-13",
    "place": "会议室 A"
  }
]
JSON
```

首次运行会弹出系统授权框，请在弹窗中点击「允许」，授予完全访问提醒事项的权限。

### JSON 字段

| 字段      | 必填 | 说明                                                            |
| ------- | -- | ------------------------------------------------------------- |
| `title` | ✅  | 提醒标题                                                          |
| `due`   | ✅  | 到期时间。`yyyy-MM-ddTHH:mm`（本地时区）或纯日期 `yyyy-MM-dd`（默认当天 09:00 推送） |
| `place` | ❌  | 地点，写入提醒的地点字段                                                  |
| `notes` | ❌  | 备注，原样写入                                                       |

### 成功输出

脚本以 `DONE count=N` 结尾表示全部成功，每条以 `OK\t标题\t到期\t地点\t清单\t标识` 输出：

```
OK	去朝阳医院复查	2026-11-12T10:00	朝阳医院门诊楼三层	提醒	ABC-123
DONE count=1
```

只认 `DONE` 行判定成功；出现错误信息、编译错误或非 0 退出码即为失败。

## 作为 Agent Skill 使用

本项目核心是给 AI Agent 消费的 **契约 + 执行腿** 结构：

- `SKILL.md` 定义了「触发契约」——把用户一段口语化的「提醒：……」文本拆解成若干条 JSON（提取标题、时间、地点、备注；相对时间按当前时刻换算；缺时间的条目直接终止报错而不是猜）。
- `WriteReminders.swift` 是执行腿，把 JSON 落地到系统提醒事项并校验。

在支持 Agent Skill（如 WorkBuddy 等）的环境中，把本仓库 `SKILL.md` 与 `scripts/` 放入技能目录（例如 `~/.workbuddy/skills/apple-reminders/`），Agent 收到「提醒：……」类消息即自动按契约写入。

**执行腿无平台依赖**：`SKILL.md` 的拆条契约在任意系统都成立，只需替换对应平台的执行腿即可移植。

---

## 注意事项

- 只写入默认提醒清单（`defaultCalendarForNewReminders`）。如需指定清单需修改脚本。
- 时间一律按**本机时区**解释，脚本不做时区转换。
- 到点通知使用绝对时间闹钟（`EKAlarm(absoluteDate:)`）。
- 脚本不会代替用户执行提醒里的实际事务，只负责记录提醒。

## 跨平台说明

| 平台            | 可用性 | 说明                                     |
| ------------- | --- | -------------------------------------- |
| macOS         | ✅   | 当前原生实现                                 |
| Windows       | ❌   | 无 EventKit，需改用 Windows 闹钟/待办 API 重写执行腿 |
| iOS / Android | ❌   | 沙盒限制，第三方脚本无法直写系统提醒，需改用系统提供的调用机制        |

`SKILL.md` 的契约逻辑可跨平台复用，只需为各平台提供对应执行腿。
